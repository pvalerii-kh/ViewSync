# ViewSync — публічні релізи

Тут публікуються **готові збірки** фонового агента ViewSync для Windows (оновлення програми).

- Кожна версія — окремий [Release](https://github.com/pvalerii-kh/ViewSync/releases) (tag на кшталт `v0.1.2a`).
- У релізі — архів із `ViewSync.exe` (і пізніше `ViewSyncUpdater.exe`).
- Вихідний код агента зберігається в окремому (приватному) репозиторії розробки.

Агент перевіряє наявність нової версії за маніфестом `latest.json` (з’явиться після впровадження автооновлення).
